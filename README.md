I'm a final-year **Software Engineering** undergraduate at the **University of Kelaniya, Sri Lanka**, with hands-on experience building full-stack web applications, mobile applications, Chrome extensions, REST APIs, and AI-enabled solutions. I enjoy taking ideas from initial requirements and interface designs through backend development, database integration, testing, and deployment. Through internship, academic, research, and client projects, I have strengthened my ability to solve technical problems, improve existing systems, and collaborate effectively within development teams.

- 💻 Build full-stack applications using **React, Next.js, TypeScript, Node.js, Express, NestJS, and Spring Boot**
- 🎨 Create responsive, user-focused interfaces and translate **Figma designs** into functional web experiences
- ⚙️ Develop and integrate **REST APIs, JWT authentication, role-based access control, AI services, and third-party APIs**
- 📱 Build cross-platform mobile applications using **React Native** and **Flutter**
- 🗄️ Work with **PostgreSQL, MySQL, and MongoDB**, including database integration using **Prisma**
- 🧩 Experienced in developing and improving production web applications and Chrome extensions through debugging, refactoring, streaming responses, automation workflows, and usability enhancements
- 🔭 Currently contributing to **ConstructPro ERP**, developing **Kochi Guru Pizza** for a client, and working on **CloudHeal**, an AI-assisted CI/CD failure-resolution research project
- ✍️ Share software engineering knowledge and project experiences through articles on [Medium](https://medium.com/@isharadh2002)
- 🏆 Top 10 team at **JuniorHack 2024** and 1st Runner-Up in an **Inter-Faculty Mathematics Competition** at the University of Kelaniya
- 🎯 Continuously expanding my skills across **frontend development, backend systems, mobile development, software architecture, AI integration, and cloud deployment**
